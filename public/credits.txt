ASTRA — THE TRIBOAR TRAIL / ASSET & LIBRARY CREDITS

This is an unofficial Dungeons & Dragons-inspired environment prototype.
Dungeons & Dragons, Forgotten Realms, Phandalin, and related setting names
belong to their respective rights holders. No official affiliation is claimed.
The user supplied a Goblin Ambush reference map. Its image is not bundled;
the continuous environment and in-game cartography are recreated in code.

ORIGINAL ENVIRONMENT MATERIALS
The earth-path, forest-soil (forest floor), leaf-litter, mossy-bark, rock,
and oak-branch source images in assets-source/ were AI-generated for this
prototype. Optimized WebP textures, alpha masks, and image-derived normal
maps were prepared locally with Sharp. These are not claimed to be
scanned/photogrammetry materials. Terrain, plants, rocks, UI, and map
graphics are procedural.

CHARACTER
The hero is an original skeletal 3D rig built procedurally in code
(geometry, jointing, and canvas-painted albedo maps for mail, plate,
leather, blades, wood, and hair; see src/character/skeletal/).
Six AI-generated portrait paintings (three male, three female) are bundled
as size-optimized WebP faces for the character-creation portraits.
Seven AI-generated weapon-card paintings (longsword, battleaxe, warhammer,
shortsword, longbow, quiver, shield) appear in the creation screens and
item detail views.

CREATION-SCREEN ART
AI-generated, size-optimized to WebP (scripts/prepare-creation-assets.mjs):
the class banner (Fighter), species banner (Human), background banner
(Soldier), the gilded arch frame, the parchment background, and the dragon
wax seal. The rest time-lapse sky pair (sky_night, sky_dawn) is generated
procedurally in that script — seamless equirectangular gradients with
period-wrapped starfields.

ANIMALS
The Wanderer, the yoked oxen, and the horses are original procedurally
painted canvas sprite sheets (sixteen direction variants per actor, with
idle, walk, sprint, seated, and head-down animation frames), displayed on
upright billboards that crossfade between neighbouring directions.

DICE & PARTICLES
The ivory dice-body PBR set and the dragon dice tray are size-optimized
WebP conversions of AI-generated sources (scripts/prepare-system-assets.mjs);
normal maps are derived, not photogrammetry scans. Dust motes, campfire
embers, and smoke are fully procedural (shader/canvas) — no sprite files
are bundled.

AUDIO
Ambient, SFX, and narration playback is synthesized/decoded locally. All
narration passages are an AI-generated spoken performance in the voice
auditioned and selected for this session, using the user's provided story
text; no API key is required for playback. The optional Gemini
regeneration script (scripts/generate-narration-gemini.mjs) uses a private
environment key and is not run automatically or called from browser code.
Ambient beds and one-shot SFX are synthesized with the Web Audio API.
